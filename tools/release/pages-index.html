从脚本堆到可管理的工作区

PyRunner 不接管你的文件结构，而是在现有目录之上提供清晰、可追踪的运行体验。

▤

脚本库自动整理

登记常用目录后自动扫描脚本，支持分类、搜索与收藏。删除登记不会删除磁盘上的源文件。

›_

真实交互式终端

WebView2、xterm.js 与 ConPTY 组成原生终端链路，保留输入、中断和多标签运行体验。

✎

离线代码编辑

保留编码、BOM 与换行格式，保存前检查外部修改，并为异常退出提供有限恢复草稿。

◷

应用内定时任务

为重复工作设置执行计划。任务只在 PyRunner 打开时触发，不注册 Windows 任务计划。

≡

运行记录有迹可循

每次执行都记录状态、时间和退出代码。切换终端标签时，脚本信息与运行状态始终同步。

本地优先，边界清楚

你的脚本，默认只留在你的电脑。

PyRunner 不上传脚本、路径、解释器设置或运行历史。编辑器和终端资源随应用离线分发。

开始使用

为 Windows 与 Python 工作流而生

系统要求

  • Windows 10 1809 或更高版本，推荐 Windows 11
  • x64 处理器
  • Microsoft Edge WebView2 Runtime
  • 至少一个可用的 Python 解释器

安装说明

  • 安装到当前用户目录，无需管理员权限
  • 卸载或覆盖升级不会删除本地数据库与设置
  • 安装包未签名，Windows 可能显示未知发布者提示
  • 可在 GitHub Release 页面核对 SHA-256
