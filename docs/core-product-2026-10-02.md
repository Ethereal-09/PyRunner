# 回归脚本管理核心功能

当前产品保留脚本目录管理、Python 解释器选择、离线代码编辑器、终端运行和停止、运行历史、应用内定时任务、主题语言设置、软件更新。

移除 AI 导航和页面、模型设置及凭据服务、模型网络请求、会话存取、上下文与补丁桥接、代码生成和依赖检测、pip 安装服务。选择脚本不再启动依赖检测或访问包索引。编辑器重新生成离线资源，仅保留普通文件编辑功能。

兼容性：保留既有编号的数据库迁移（包括历史 004 迁移），确保旧数据库可以继续升级。历史 AI 数据、用户文件和凭据不主动删除；当前软件不再读取或使用这些功能数据。旧版本更新日志和此前审查报告属于历史记录，以本说明为当前功能边界。

定时任务仍仅在应用打开时运行。

验证：Release 构建 0 警告、0 错误；146 项核心服务检查通过；真实窗口验证设置取消与保存、历史和定时任务布局、脚本运行与停止、运行中关闭确认。独立测试数据目录使用独立实例锁，同一数据目录保持单实例。

新版可执行文件位于 `artifacts/core-release/PyRunner.exe`。原 Release 输出仍被用户正在运行的旧版占用，因此此次使用独立输出目录，没有关闭用户窗口。
