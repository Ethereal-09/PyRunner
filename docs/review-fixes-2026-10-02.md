# UI 与运行逻辑修正记录

本报告记录精简前的审查与修正。随后按用户要求移除 AI 和依赖检测功能，当前边界以 [核心功能说明](core-product-2026-10-02.md) 为准。

本轮保留已有界面结构及工作区中原有修改，修正交互语义、异常反馈与窄窗口显示。

## 修改内容

- 运行选项、语言使用设置草稿，确定后保存，取消丢弃；目录、解释器和 AI 分组内即时操作在页面明确说明。
- 缩短设置分类导航，补充目录、解释器移除按钮的提示和无障碍名称。
- 关闭运行中的终端标签或窗口需要确认，默认选择取消。
- 指定工作目录不存在时阻止启动，避免静默切换目录。
- 目录监听处理普通目录新增、改名、删除，忽略普通输出文件新增以减少无效刷新。
- 历史与定时任务区分加载失败和空列表，提供重试；任务更新失败提供可见反馈。
- 定时任务保存启动失败原因，显示上次时间和诊断，增加运行历史入口；持续说明仅应用打开期间调度、休眠补触发、同脚本运行中跳过的规则。
- 新增独立迁移 005，不修改已发布迁移；启动时修正遗留运行状态，并用单实例锁避免另一进程误修正活跃记录。
- 顶部“运行”改为“运行历史”；历史页增加列标题、指标换行、窄屏卡片。
- AI 页按内容区宽度调整标题操作与模型选择器，减少截断；侧栏宽度受窗口比例限制；完整脚本路径可悬浮查看。
- 调度交互拆至 MainWindow.Scheduling.cs，减少主窗口职责混杂。
- 同步 README 与 AI 页面文案：实际会话保存在本机；确认应用修改后会备份并写入文件，提供手工恢复说明。
