# 脚本退出提醒修复

问题：成功启动的脚本返回非零退出码时，原先复用“无法运行脚本”弹窗，混淆了启动失败与执行结果，并阻塞用户操作。

修复：运行编排发布包含实际退出码的终结事件；主窗口用可关闭的 InfoBar 呈现失败提醒。已启动的脚本显示“脚本执行已结束”和实际退出码，未能启动的脚本显示启动失败说明。正常退出和主动停止不显示失败提醒；再次运行清除旧提示。提醒开关保持有效，中英文文案同步。

运行历史保留真实结果：0 为成功，其他退出码为失败，主动停止为 killed。没有把退出码 2 硬编码为成功。

用户截图对应的清理脚本经只读检查，在遇到占用文件或权限不足并跳过部分项目后主动返回 2，按回车只是结束等待。此次没有执行或修改该清理脚本。

验证：Release 构建 0 警告、0 错误；核心服务回归全部通过。使用独立测试目录内无副作用脚本，真实验证停止、退出 2、退出 0、关闭提醒后退出 2，确认提醒不阻塞设置入口且数据库记录与实际退出码一致。

执行入口：`artifacts/exit-fix-release/PyRunner.exe`。
