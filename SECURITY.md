# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public GitHub Issue.

Use the repository's **Security** tab and choose **Report a vulnerability** to
submit a private GitHub Security Advisory. Include the affected version, a
minimal reproduction, expected impact, and any suggested mitigation. Avoid
including real scripts, local paths, credentials, databases, or run history.

If private vulnerability reporting is not available yet, wait for the
repository owner to enable it instead of publishing vulnerability details.

## Supported versions

PyRunner has not published its first stable release. Supported-version details
will be added when the first stable GitHub Release is available.
